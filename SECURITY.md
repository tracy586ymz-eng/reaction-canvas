# Security

This MVP has not received an independent security audit. The latest public source is the maintained version; no older release support guarantee is made.

**Do not publish a key, private endpoint, screenshot, task backup or raw provider request/response in an issue.** For sensitive findings, use this repository's private vulnerability reporting feature if enabled, or a verified private contact method listed on the maintainer's GitHub profile. If neither is available, open a public issue that only asks for a private reporting channel and contains no sensitive details.

Include the affected version, a synthetic reproduction, impact and a suggested fix. If a real credential was exposed, revoke/rotate it through the provider; removing a commit alone does not make the key safe. Avoid testing against other people's data or endpoints.
